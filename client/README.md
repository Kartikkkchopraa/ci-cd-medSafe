# medSafe

A full-screen landing page for medSafe, a drug information, contraindication and interaction checker, built with React, TypeScript, Vite, and Tailwind CSS.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The background video is controlled by horizontal mouse movement rather than autoplay. Move the pointer left/right across the page to scrub the video timeline.
